语音

APK 已内置 Fairy 的参考录音，只需填入 SiliconFlow API Key，点一下即可克隆出她本人的音色。

原理：上传一段 Fairy 的参考录音（5–10 秒，越清晰越好）以及录音里说的那句话， 服务会返回一个专属音色 ID，之后就能用她本人的声音朗读任意文字。

任何兼容 POST /audio/speech 的服务都可以接入 （自建 TTS、其它云厂商等）。请求体：model / input / voice / response_format / speed。

云语音识别（可选，系统识别不可用时用）

设备没有可用的系统识别服务时，可填入百度语音开放平台的凭据改用云识别。 凭据只保存在本机。申请地址：console.bce.baidu.com（语音技术 → 短语音识别）。

悬浮球（语音唤醒）

开启后屏幕上会出现一个小球，点一下就能直接说话，不用先打开 Fairy。 把小球拖到屏幕左/右边缘松手，它会自动收起成半个，不再挡视野； 点一下即可展开。
