语音

屏幕上的回复不会被改动，只有朗读时使用改写后的稿子。 开启 API 改写会额外消耗少量 token（用便宜快速的模型即可）。

上传一段参考录音（5–10 秒，无背景音乐），服务会返回一个专属音色 ID， 之后朗读就用这个声音。本项目不内置任何音频素材，录音请自行准备。

上传一段参考录音（5–10 秒，越清晰越好）以及录音里说的那句话， 服务会返回一个专属音色 ID，之后就能用这个声音朗读任意文字。

⚠️ 请确保你拥有所上传录音的使用权。克隆他人声音可能涉及人格权或 著作权，请仅在合法授权范围内使用，勿用于冒充他人或违法用途。 本项目不提供、也不分发任何音频素材。

任何兼容 POST /audio/speech 的服务都可以接入 （自建 TTS、其它云厂商等）。请求体：model / input / voice / response_format / speed。

云语音识别（可选，系统识别不可用时用）

设备没有可用的系统识别服务时，可填入百度语音开放平台的凭据改用云识别。 凭据只保存在本机。申请地址：console.bce.baidu.com（语音技术 → 短语音识别）。

界面

对话区背景是程序化绘制的终端风格图层（网格、扫描线、数据刻度）， 界面元素半透明地融入其中。

0 = 传统卡片（最清晰）；1 = 完全融入背景。 调低可提升可读性，调高更接近游戏内 HDD 界面的观感。

提示音由 Web Audio 实时合成，不含任何音频素材文件。

联网搜索

开启后，涉及实时信息的问题（新闻、价格、天气、最新版本等） 会先联网检索，再结合结果回答，并标注来源。 不需要 API Key，直接用公开搜索结果。

悬浮球（语音唤醒）

开启后屏幕上会出现一个小球，点一下就能直接说话，不用先打开 Fairy。 把小球拖到屏幕左/右边缘松手，它会自动收起成半个，不再挡视野； 点一下即可展开。
