处理：
- 默认模型改为 deepseek-flash（快、便宜、支持视觉）
- 下拉列表加入 deepseek-v4-pro，可按需手动切换
- 保留 deepseek-chat / deepseek-reasoner 作为兼容选项（旧名可能仍被
  服务端接受并映射到新模型），避免既有配置直接失效

v4-pro 输入 0.66 / 输出 1.98 美元，约为 flash 的 4-5 倍。

二、朗读文本改写

屏幕上的回复是 Markdown，直接念会听到 #、**、|---|，代码还会被逐字符读。
现在朗读时改用口语稿，分两级：

1. 本地清洗（始终执行，零延迟零成本）
   围栏代码块 -> "（这里有一段代码，共 N 行）"
   表格 -> 逐行转成"列名是值"的叙述
   链接 -> 只留文字；标题去 #；强调去 **；列表去符号
   并整理标点，避免"即可：。（这里有一段代码…"这类断裂停顿

2. API 口语化（可选，调用 deepseek-flash）
   长句拆短、书面语转口语、数字与缩写按中文读法写

关键约束：屏幕上的回复不会被改动。改写结果只传给 TTS，
显示、存库、发给模型上下文的一律是原文 —— 否则会污染对话历史，
之后重新生成或编辑消息都会带着改写稿。

改写模型固定用 flash：这是简单任务，用 v4-pro 做性价比很低。

设置里新增「预览改写效果」：同时展示原文、本地清洗结果与 API 改写结果，
便于判断是否合意（仅靠听很难对比）。
