新增文字区遮罩：背景铺满融入，但正文区域保持干净

问题：之前背景网格直接穿过文字区域。网格虽然很淡，但长文本阅读时
会有"字和线混在一起"的感觉，标题、按钮、气泡正文都受影响。

方案：在网格与扫描线**之后**叠一层椭圆渐变遮罩，
用底色把正文区域的网格压掉。

几个取舍：

1. 用椭圆而非矩形
   矩形边缘会形成一条生硬的直线，反而更显眼；椭圆边界柔和，
   过渡自然，看起来像光照范围而不是"贴了块板子"。

2. 用底色而非黑色或白色
   用底色才能让网格"消失"而不改变整体明暗，
   否则文字区会变成一块突兀的色斑。

3. 遮罩画在 Canvas 内部而非用 CSS
   背景是 Canvas 绘制的，用 CSS 叠一层会同时遮住立绘与其他元素；
   在绘制流程里插一步，只影响网格与扫描线，范围精确。

4. 做成可调滑块（0-1，默认 0.72）
   不同屏幕亮度与个人偏好差异大，写死一个值必然有人觉得太糊或太透。
   0 = 网格完整透出，1 = 文字区完全压平。

遮罩在亮/暗主题下使用各自底色，因此切换主题不会出现色差。

验证：APK 验收 51 项。新增两条断言：
- 遮罩滑块存在且默认 0.72
- 遮罩确实改变绘制结果（关闭时中心像素 RGB(28,43,60) 有网格，
  开启后 RGB(13,19,27) 为纯底色）
契约 37、原生桥 22、悬浮球 30、语音场景 8，全部通过。
