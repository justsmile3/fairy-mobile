# 用上自定义音色（语音克隆）

这份文档说明如何让应用用**指定的声音**朗读。

核心原理：**用一段参考录音，到云端服务上克隆出一个专属音色**，
之后就能用这个音色朗读任意文字。

> ⚠️ **本项目不提供、不分发任何音频素材。** 参考录音需你自行准备。
> 若你想克隆某个角色或他人的声音，请先读
> [下面的合规提醒](#️-关于录音的合规提醒重要) —— 这涉及著作权与人格权。

---

## 为什么不用本地模型

项目早期尝试过在手机本地跑语音克隆（ZipVoice + sherpa-onnx），但遇到两个硬限制：

1. **Android 不允许从包外加载原生库**
   targetSdk ≥ 24 时，`dlopen` 应用私有目录里的第三方库会被 linker 拒绝
   （[官方行为变更](https://developer.android.google.cn/about/versions/nougat/android-7.0-changes#ndk)）。
   而 `System.loadLibrary` 只认 APK 内的库 —— 所以原生库必须打进包。

2. **打进包会导致部分设备启动崩溃**
   库加载发生在类加载阶段，早于 `onCreate`，`try/catch` 拦不住。

走云端 API 则完全规避这两个问题，而且**效果通常更好**（云端模型更大、更自然）。

---

## 方案：SiliconFlow（推荐）

[SiliconFlow](https://cloud.siliconflow.cn) 是国内可直连的模型服务平台，
提供 OpenAI 兼容的语音合成接口，**并支持上传参考音频克隆音色**。

### 步骤

**1. 注册与实名**

访问 [cloud.siliconflow.cn](https://cloud.siliconflow.cn) 注册。
上传音色（克隆）功能需要**实名认证**，在「账户管理」里完成。

**2. 创建 API Key**

进入「API 密钥」页面新建一个，形如 `sk-xxxxxxxx`。
新用户通常有赠送额度，语音合成单价很低。

**3. 在 Fairy 里配置**

打开 Fairy → 设置 → 语音：

- **语音合成方式**：选 `SiliconFlow（支持克隆 Fairy 音色）`
- **API Key**：粘贴刚才创建的 Key
- **模型**：`CosyVoice2-0.5B`（支持克隆，推荐）

**4. 克隆音色**

> ⚠️ **本项目不提供、不分发任何音频素材。** 参考录音需**你自行准备**。
> 如果你打算用某作品角色的语音，请先阅读下面的合规提醒。

点设置 → 语音 → **「上传录音克隆音色」**（或顶部的「🎙 克隆音色」），
选择你准备好的录音文件，等待几秒到几十秒即可。

上传成功后：
- 音色 ID 会自动填入「音色 ID」栏
- 界面提示 `克隆成功！音色 ID：speech:xxx:yyy:zzz`
- 自动试听一句确认效果

**参考录音的要求**

| 要求 | 说明 |
| --- | --- |
| 时长 | 5–10 秒（服务上限 30 秒） |
| 内容 | 一段完整、自然的话，不要只有一两个词 |
| 质量 | 无背景音乐、无噪音、无混响 |
| 格式 | wav / mp3 / m4a / aac / ogg / flac 均可 |

**还要填「参考录音对应的文字」**

这是克隆接口的**必填参数**，必须和录音里逐字说的内容**完全一致**（含标点）。

## ⚠️ 关于录音的合规提醒（重要）

克隆音色这件事本身是中立的技术能力，问题在于**你用什么声音去克隆**。

| 风险 | 说明 |
| --- | --- |
| **著作权** | 游戏语音、影视台词通常受著作权保护，未经许可的使用可能构成侵权 |
| **人格权 / 声音权** | 未经许可克隆他人声音（尤其是真人配音演员），可能侵害其人格权。中国《民法典》第 1023 条对声音保护有明确规定 |
| **平台条款** | 使用游戏素材通常违反该游戏的用户协议 |
| **冒充风险** | 用克隆音色冒充他人、制作虚假内容，可能触犯法律 |

**请确保：**

1. 你拥有所上传录音的合法使用权（例如用**自己的声音**，或已获授权的素材）；
2. 你的使用属于**个人学习、研究或欣赏**等合理范围，不做商业用途；
3. 不用于冒充他人、不制作违法或侵权内容。

本项目作者不对你如何使用该功能负责。详见
[NOTICE.md](../NOTICE.md)。

## 手写代码也能克隆（备选）

如果你更习惯命令行，官方接口是这样的：

```bash
curl -X POST "https://api.siliconflow.cn/v1/uploads/audio/voice" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@fairy.wav" \
  -F "model=FunAudioLLM/CosyVoice2-0.5B" \
  -F "customName=fairy" \
  -F "text=主人，我是fairy。语音系统已经准备就绪，随时为您提供帮助。"
```

返回：

```json
{ "uri": "speech:fairy:xxx:xxx" }
```

把 `uri` 填到 Fairy 设置的「音色 ID」栏即可。

> 注意 `model` 和 `customName` 和 `text` 都是必填。
> `audio` 也支持 base64（`data:audio/mpeg;base64,...`）而不是文件上传。

**查询已上传的音色**：`GET /v1/audio/voice/list`
**删除音色**：`POST /v1/audio/voice/deletions`

---

## 5. 完成

设置里出现音色 ID 后，所有朗读都会用 Fairy 的声音：

- 点「试听」立即验证
- 打开「自动朗读回复」，她的每句回复都会念出来

想换回别的音色，把「音色 ID」清空即可（会退回服务预置音色 alex）。

## 参考录音从哪来

**需要你自己准备。** 本项目不内置任何音频素材，原因见上文的合规提醒。

几种合法可行的来源：

| 来源 | 说明 |
| --- | --- |
| **你自己的声音** | 最没有争议，用手机录一段 5–10 秒的清晰语音即可 |
| **你有权使用的素材** | 例如你自己创作的内容、已购买授权的音源、明确允许使用的开源语音数据集 |
| 公共领域 / CC0 语音 | 可用于任意用途，无版权顾虑 |

录音时的建议：

- 用手机自带录音机即可，安静环境下录，**不要有背景音乐**
- 说一段**完整自然的话**（10–20 个字以上），不要只念一两个词
- 格式 wav / mp3 / m4a 都行

> 小技巧：选**语速平稳、情绪中性**的片段，克隆出来的音色更稳定。
> 带强烈情绪（喊叫、大笑）的片段会让音色偏移。

## 其它可选服务

### 自定义（OpenAI 兼容）

设置 → 语音 → **语音合成方式** 选 `自定义`，填写：

| 字段 | 说明 |
| --- | --- |
| Base URL | 服务地址，如 `https://your-host/v1` |
| API Key | 可留空 |
| 模型名 | 如 `tts-1` |
| 音色名 | 如 `zh-CN-female` |

Fairy 会向 `{Base URL}/audio/speech` 发 POST 请求：

```json
{
  "model": "tts-1",
  "input": "要朗读的文字",
  "voice": "zh-CN-female",
  "response_format": "mp3",
  "speed": 1.0
}
```

任何兼容这个格式的服务都能接入，包括自建 TTS、其它云厂商等。

### 百度翻译语音（免注册）

设置 → 语音 → 选 `百度翻译语音`。

**开箱即用，不需要任何 Key**，但音色是固定的，**不能克隆**。
适合"先能用起来"，想要 Fairy 音色请用 SiliconFlow。

### 自动选择

默认的 `自动选择` 规则：填了 SiliconFlow Key 就用它，否则用百度。
这样不配置也能出声，配置了自动升级。

## 常见问题

**试听没声音 / 提示 HTTP 401**
API Key 填错或已失效。到 SiliconFlow 控制台确认。

**提示 HTTP 403**
克隆功能需要实名认证。在控制台完成实名后重试。

**提示 HTTP 402**
账户余额不足，充值即可。语音合成单价很低，几块钱能用很久。

**克隆音色听起来不太像**
参考录音的质量是关键。换一段更清晰、更长的录音（接近 10 秒）重试。

**文字里的英文读得怪**
中英混合时，模型可能按中文发音规则处理英文。
可以试试 `fish-speech-1.5` 模型，它对中英混合更自然。

**想换回系统语音引擎**
在设置里把「语音合成方式」改成不使用云服务的选项，
或用「系统语音设置」跳转到系统 TTS 配置。

## 隐私说明

- API Key 与音色 ID **只保存在本机**（WebView 的 localStorage / IndexedDB）
- 朗读时文本会发送给你选择的服务商（SiliconFlow / 百度 / 自建），这是合成所必需的
- 不上传任何其它数据；会话记录、设置全部留在本机
- 使用百度免注册方案时，文本会发往百度翻译的公开接口
